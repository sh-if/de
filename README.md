# Design Explorer link

## Syntax:
https://cdn.jsdelivr.net/gh/USER/REPO@BRANCH/FOLDER/


## For my github:
**Example project:**
https://github.com/sh-if/de/tree/main/Campsie_run01

**The Design Explorer link is:**
https://cdn.jsdelivr.net/gh/sh-if/de@main/Campsie_run01/


**If the data was nested deeper, for example:**
https://github.com/sh-if/de/tree/main/DesignExplorer/Projects/Campsie_run02

**The jsDelivr version would be:**
https://cdn.jsdelivr.net/gh/sh-if/de@main/DesignExplorer/Projects/Campsie_run02/
